# AI Productivity Hub

Build a modern, professional and responsive web application called "AI Workplace Productivity Assistant".

The application is an AI-powered workplace productivity platform that helps professionals save time and improve productivity.

Include these five main AI features:

1. Smart Email Generator

2. Meeting Notes Summarizer

3. AI Task Planner / Scheduler

4. AI Research Assistant

5. AI Workplace Chatbot

DESIGN:

- Create a clean, modern professional dashboard.

- Use a professional blue, white and light-gray colour scheme.

- Include a left sidebar navigation on desktop.

- Make the sidebar responsive on mobile.

- Use cards, rounded corners, subtle shadows and clear typography.

- Create a responsive layout that works on desktop, tablet and mobile.

- Include icons for each feature.

- Add loading states and empty states.

- Make the interface feel like a real workplace SaaS application.

SIDEBAR:

- Dashboard

- Smart Email

- Meeting Notes

- Task Planner

- Research Assistant

- AI Chatbot

- Settings

DASHBOARD:

Create a dashboard containing:

- Welcome section

- Productivity overview

- Number of emails generated

- Number of meetings summarized

- Pending tasks

- Recent activity

- Upcoming tasks

- Quick action buttons for each AI tool

SMART EMAIL GENERATOR:

Create an input section where the user can:

- Enter the purpose of the email

- Enter additional details

- Select recipient type

- Select tone: Formal, Friendly, Persuasive

- Select length: Short, Medium, Long

Generate a professional email based on the user's input.

The output should include:

- Subject

- Email body

Add buttons:

- Copy

- Edit

- Regenerate

- Clear

MEETING NOTES SUMMARIZER:

Allow users to paste or enter long meeting notes.

Generate:

- Meeting summary

- Key decisions

- Action items

- Deadlines

- Responsible people

Display each category in a separate card.

Add buttons:

- Copy summary

- Edit

- Regenerate

- Clear

AI TASK PLANNER:

Allow users to enter multiple tasks.

For each task allow:

- Task name

- Priority

- Deadline

- Estimated time

AI should organize tasks into a practical daily or weekly schedule.

Display:

- High priority tasks

- Medium priority tasks

- Low priority tasks

- Suggested schedule

- Completed tasks

Allow users to mark tasks as complete.

AI RESEARCH ASSISTANT:

Create an input area where users can enter a research question or topic.

Allow the user to select:

- Quick summary

- Detailed summary

- Key insights

- Recommendations

Display the AI response in structured sections.

Include a source/reference area where appropriate.

AI CHATBOT:

Create a modern chat interface for an AI workplace assistant.

Include:

- User messages

- AI responses

- Chat history

- Typing/loading indicator

- Suggested prompts

Suggested prompts:

"Write a professional email"

"Summarize my meeting notes"

"Plan my day"

"Research this topic"

RESPONSIBLE AI:

Include a visible Responsible AI disclaimer throughout the application.

Use this disclaimer:

"AI-generated content may contain errors or inaccurate information. Always review and verify important information before using it for workplace decisions or communication. Do not enter confidential, sensitive, or personal information."

PROMPT ENGINEERING:

Use structured prompts for each AI feature.

Prompts should clearly define:

- Role

- Task

- Context

- Instructions

- Expected output format

- Tone

- Constraints

Make AI responses structured, professional and easy to edit.

USER EXPERIENCE:

- Include clear input and output sections.

- Show loading states while AI responses are being generated.

- Show helpful error messages.

- Prevent empty submissions.

- Allow users to regenerate responses.

- Allow users to copy AI-generated content.

- Keep navigation simple.

- Make all buttons functional.

- Ensure the application looks polished enough for an academic project presentation.

Create realistic sample data so the dashboard looks populated when first opened.

Make the entire application feel like a functional AI workplace productivity product rather than a simple static website.
